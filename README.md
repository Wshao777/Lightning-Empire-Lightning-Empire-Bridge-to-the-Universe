這樣可以讓高鐵位於中央，降低強風直接吹襲列車的影響。

二、兩側擋風設施的功能

• **降低側風：**採用經風洞測試的透風式擋風屏。

• **降低風壓變化：**避免列車突然受到強烈側風。

• **降低飛散物風險：**保護軌道及列車。

• **AI風速監測：**風速超標時警示、降速或暫停列車。

注意：擋風屏不能保證颱風期間照常行駛，還必須設置風速監測及停駛標準。

三、三座橋統一規格

 
• 北線：中央高鐵＋雙側擋風。

• 中線：中央高鐵＋雙側擋風。

• 南線：中央高鐵＋雙側擋風。

二、風力發電＋海洋養殖

 
這個方向稱為海上多用途利用（Multi-use Offshore）。

可以研究：

• 風力發電供應養殖設備。

• AI監測水溫、鹽度、溶氧。

• 海藻吸收養殖環境中的部分營養鹽。

• 自動化餵食及魚群健康監測。

• 海洋環境長期監測。

但風機基礎附近不代表天然就是良好養殖場，必須先調查海流、波浪、水質及生物承載量。
