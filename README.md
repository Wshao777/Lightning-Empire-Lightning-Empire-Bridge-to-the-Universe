## 一、核心修正

1. 「AI十項全能」修正為「AI跨域整合十項能力地圖」。
2. 「徐志曆是十項專業」修正為「徐志曆負責願景整合、計畫發起與開發規劃；工程設計與法定簽證由合格專業人員負責」。
3. 「股票上漲」不列為目標；產業機會必須用合約、訂單、營收、獲利、現金流與估值驗證，不提供個股推薦或股價預測。
4. 「廢棄汽車加水泥做橋樑」修正為：廢車拆解、分類、回收鋼材與再生骨材，經冶煉、檢測及符合結構工程規範後，評估用於合規材料；不得整車灌入水泥作為橋墩或主結構。
5. 跨海大橋屬跨境大型公共工程構想，須雙方政府協議、海域協調、環評、地質地震颱風海流調查、融資與維護基金；截至2025年11月，台灣陸委會公開表示無推動兩岸跨海橋梁政策或計畫，故目前僅能視為民間研究構想，不能視為已獲同意。
6. 警消護理調薪是獨立公共政策議題；56,000元調至77,000元為增加21,000元、調幅37.5%，屬政策假設，須財政評估，不與建橋收益混同。
7. 風電提撥1,130億元、加薪730.86億元、剩餘399.14億元均為假設性試算，未取得授權前不得視為建橋預算。

七、废弃汽车资源循环再利用

资源回收方向：废弃汽车拆解、钢铁分类及回收、金属材料重新冶炼、合格再生钢材检测、再生建材研究、混凝土再生骨材研究。
